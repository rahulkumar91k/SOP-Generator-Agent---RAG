Server Reboot and Pending Restart Issues

Symptoms
- The server is stuck on "Working on updates" or "Undoing changes" after a restart.
- A reboot takes far longer than normal, or the server does not come back online.
- New software or patches cannot install because a reboot is pending.
- The server restarted unexpectedly outside the maintenance window.

Common causes
- A pending reboot flag from a previous update or software installation.
- An update rolling back because it could not complete.
- A service with a long shutdown timeout blocking the restart.
- A scheduled task, group policy or maintenance window triggering an unplanned restart.
- Hardware or firmware faults causing an unexpected shutdown.

Troubleshooting steps
1. Detect a pending reboot by checking these registry locations:
   HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Component Based Servicing\RebootPending
   HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsUpdate\Auto Update\RebootRequired
   HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\PendingFileRenameOperations
2. Schedule and perform a controlled restart:
   shutdown /r /t 0     or     Restart-Computer -Force
3. If the server hangs during boot, use out-of-band management such as iDRAC or iLO to watch the console, and wait for an update rollback to finish rather than powering off.
4. Review the last shutdown reason in the System event log: event ID 1074 for planned restarts, 6008 for unexpected shutdowns, and 41 from Kernel-Power.
5. Check uptime with: Get-CimInstance Win32_OperatingSystem | Select LastBootUpTime
6. If a service delays shutdown, identify it in the System log and stop it manually before the next restart.

Resolution
Clear the pending reboot by completing a controlled restart during a maintenance window, and allow any in-progress update rollback to finish. Investigate event ID 6008 or Kernel-Power 41 entries for hardware causes before repeating the restart.

Verification
- The pending reboot registry keys are no longer present.
- LastBootUpTime reflects the new restart time.
- All automatic services are running and the previously blocked installation or patch now proceeds.
